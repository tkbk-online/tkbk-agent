## Что сделано

- Форк `cline/cline` → `tkbk-online/tkbk-agent`, лицензия Apache 2.0 и NOTICE с атрибуцией Cline.
- Провайдер **TKBK** по умолчанию: `https://api.tkbk.online/v1`, Claude через Anthropic Messages, остальные через OpenAI-совместимый endpoint, каталог из 7 моделей + живой `GET /v1/models` по ключу.
- Кнопки «Войти через Telegram-бота» (tkbk.online/login) и «Купить ключ» (tkbk.online/buy) в настройках провайдера и на экране первого запуска; экран первого запуска на русском.
- BYOK-провайдеры Cline (OpenAI, Anthropic, Gemini, OpenRouter, Ollama и др.) сохранены.
- Скилы `SKILL.md` из `.tkbk/skills` проекта и `~/.tkbk/skills`; пять стартовых скилов ставятся при первом запуске.
- Бренд: имя «TKBK Agent», publisher `tkbk-online`, id `tkbk-online.tkbk-agent`, иконки, русские названия команд и walkthrough, кнопка аккаунта Cline скрыта.
- Свой каталог данных `~/.tkbk` (история, настройки, ключи, скилы) — не пересекается с `~/.cline`; телеметрия выключена по умолчанию без уведомлений; API `getApiKey()` / `onDidChangeApiKey` для автодополнения TKBK IDE.
- Тесты: провайдер TKBK (llms), живой каталог (core), пути скилов (shared), установщик скилов и UI провайдера (расширение).

## Уровень «умного агента» (16.10)

- **Субагенты**: включены в VS Code; роли `explore` / `implement` / `test` / `review` в `~/.tkbk/agents` (управляемые файлы), `explore` на быстрой модели TKBK (`tkbk-agent.subagents.*`). Параллельность ограничена лимитом SDK (8 вызовов инструментов за итерацию), отдельного лимита «4 субагента» нет.
- **Фоновые задачи**: панель «Фоновые задачи», worktree на задачу, headless-сессия без подтверждений, Применить (3-way apply) / diff / отчёт / открыть / отклонить. Free — 1 параллельно, Pro — 3. Облачный запуск не реализован (это у сессии Cloud Agents).
- **Индекс кода**: лексический BM25 всегда, семантика через `POST /v1/embeddings` шлюза при ключе TKBK (модель `text-embedding-3-small` — проверить, что шлюз её отдаёт; при 4xx индекс тихо работает лексически). Локальной ONNX-модели нет: onnxruntime-node — нативный бинарник под каждую ОС, в один .vsix не влезает без per-platform сборок.
- **Умные дефолты**: правило `~/.tkbk/rules/tkbk-agent.md` (план-чеклист, цикл тестов ≤3, память проекта `.tkbk/memory.md`, когда звать субагентов, `codebase_search` первым), кнопка «Проверить изменения».
- **Tab**: перенесён в расширение (`tkbk-agent.tab.*`, статус-бар «TKBK Tab»): FIM-промпт, недавние правки, debounce 150 мс, отмена, кэш, single/multiline, исключение секретов, выбор модели из `/v1/models`. tkbk-complete в TKBK IDE станет внешним резервом. «Следующая правка» не реализована.
- **Облако**: «Фоновая задача в облаке…» по контракту TKBK Cloud Agents (клиент вендорен в `src/services/tkbk/cloud/`), сервер настраивается `tkbk-agent.cloud.serverUrl`; выгрузка незакоммиченной рабочей копии (`source: upload`) не реализована — только `repoUrl` + ветка.
- **Автоконтекст**: активный файл, вкладки, диагностика, ветка, `git status`/`diff --stat` — в системный промпт при старте задачи (`src/services/tkbk/autocontext.ts`). Память проекта — `.tkbk/memory.md`.
- **Проверено без реального ключа**: все новые модули покрыты unit-тестами (менеджер фоновых задач, индекс, роли, транслейтор); живой прогон субагентов, эмбеддингов и фоновой задачи с ключом `cr_…` владельцу предстоит сделать самому — у сессии ключа не было.

## Известные ограничения первой версии

- Внутри интерфейса остаётся часть английских текстов Cline (настройки, чат, подсказки). Переведены: первый запуск, настройки TKBK, команды, walkthrough, манифест, главный экран, поле ввода, панель автоподтверждения, пикер моделей, глубина рассуждений, история.
- Слово «Cline» убрано из чата, системного промпта («You are TKBK Agent»), тостов, терминала и настроек первого экрана. Остались: экраны аккаунта Cline / Cline Cloud / ClinePass (скрытая кнопка «Аккаунт», раздел Cloud в настройках, провайдеры `cline` и `cline-pass` в списке) и около сотни служебных сообщений расширения на английском — следующий проход: скрыть Cloud/Account/ClinePass и перевести сообщения.
- Ограниченный режим VS Code: расширение объявляет `untrustedWorkspaces: limited` — агент работает в недоверенной папке, но хуки из неё (`.tkbk/hooks`, `.cline/hooks`, `.clinerules/hooks`) не запускаются до нажатия «Доверять». Команды в терминале в этом режиме по-прежнему идут через обычное подтверждение; авто-подтверждение команд в недоверенной папке стоит отключать отдельно (не реализовано).
- CLI (`apps/cli`), JetBrains-плагин и настольное приложение из монорепозитория Cline не ребрендированы — только расширение VS Code.
- Синхронизация с upstream Cline: ветка `main` форка содержит правки TKBK поверх upstream; при обновлении делать `git merge upstream/main` и прогонять тесты.
