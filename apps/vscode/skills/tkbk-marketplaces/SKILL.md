# Wildberries и Ozon через MCP TKBK

Используй этот скил, когда задача касается кабинета продавца на Wildberries или Ozon: посмотреть новые заказы, остатки, цены, отзывы, отправления FBS/FBO, поменять цену, ответить на отзыв.

## 1. Проверь, подключены ли MCP-серверы

В списке доступных MCP-инструментов должны быть серверы `tkbk-wb` и/или `tkbk-ozon`. Если их нет — предложи пользователю подключить (не делай это сам без подтверждения) одним из двух способов:

**Хостинг TKBK (ничего не устанавливать)** — в настройках MCP добавить сервер с URL и заголовками:

```json
{
  "tkbk-wb": {
    "url": "https://mcp.tkbk.online/mcp/wb",
    "headers": { "Authorization": "Bearer cr_…", "x-wb-token": "…" }
  },
  "tkbk-ozon": {
    "url": "https://mcp.tkbk.online/mcp/ozon",
    "headers": {
      "Authorization": "Bearer cr_…",
      "x-ozon-client-id": "…",
      "x-ozon-api-key": "…"
    }
  }
}
```

Ключ `cr_…` — тот же, что для моделей TKBK. Подписка на MCP — https://tkbk.online/mcp.

**Локально (бесплатно, stdio)**:

```json
{
  "tkbk-wb": {
    "command": "npx",
    "args": ["-y", "github:tkbk-online/tkbk-mcp", "wb"],
    "env": { "WB_TOKEN": "…" }
  },
  "tkbk-ozon": {
    "command": "npx",
    "args": ["-y", "github:tkbk-online/tkbk-mcp", "ozon"],
    "env": { "OZON_CLIENT_ID": "…", "OZON_API_KEY": "…" }
  }
}
```

Токен WB нужен с категориями «Маркетплейс», «Цены и скидки», «Аналитика», «Вопросы и отзывы».

## 2. Как работать с данными

- Сначала **читай**, потом предлагай действие. Все изменения (цена, ответ на отзыв, статус отправления) выполняй только после явного подтверждения пользователя и повторяй, что именно изменится.
- Длинные списки серверы отдают страницами: в ответе есть `next` / `nextOffset` — передавай их в следующий вызов, пока не соберёшь нужное. Не выдумывай данные, которых не дочитал.
- На лимиты площадок (429) сервер сам ждёт `Retry-After`; если инструмент вернул ошибку лимита — подожди и повтори один раз, затем сообщи пользователю.
- Остатки WB берутся из отчёта «Остатки на складах» (Analytics API) — это сводка, а не моментальный срез склада; скажи об этом, если пользователь сравнивает цифры с кабинетом.
- Ozon: отправления FBS (`/v4/posting/fbs/list`) и FBO (`/v3/posting/fbo/list`) — это разные потоки, уточняй, какой нужен.

## 3. Типовые задачи

| Запрос пользователя | Что делать |
|---|---|
| «Что нового по заказам?» | WB: новые заказы за период; Ozon: отправления со статусом awaiting_packaging / awaiting_deliver. Сгруппируй по артикулу, покажи количество и сумму. |
| «Какие товары заканчиваются?» | Остатки по складам → отфильтруй, где остаток ≤ средним продажам за 7 дней (если есть данные), иначе ≤ 5 шт. |
| «Подними/опусти цену на X» | Покажи текущую цену и скидку, посчитай новую, спроси подтверждение, затем вызови инструмент смены цены. |
| «Ответь на отзывы» | Прочитай неотвеченные отзывы, составь ответы по скилу `tkbk-review-reply`, покажи все ответы списком, отправляй только после «да». |
| «Сделай отчёт по продажам» | Собери заказы за период, посчитай выручку, средний чек, топ-5 артикулов; оформи таблицей Markdown и предложи сохранить в файл. |

## 4. Чего не делать

- Не печатай токены площадок и ключ `cr_…` в ответах и файлах. Если они встретились в выводе инструмента — замаскируй.
- Не меняй цены массово одним вызовом без таблицы «было → станет», подтверждённой пользователем.
- Не отвечай на отзывы с личными данными покупателя.
